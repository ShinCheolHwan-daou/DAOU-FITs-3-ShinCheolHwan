## 주요 Class

### String

- String Pool
    - heap 영역에 존재
    - literal `“”` 을 이용해 문자열 객체 생성하면 String Pool에 생성
    - String은 immutable 특성이 있음 (불변)

```java
package com.lecture.classes;

public class StringTest {
    public static void main(String[] args) {
        String name = "홍길동";
        // 객체가 생성되는 heap 영역에 String Pool 영역 존재
        // ""을 사용해서 생성하면 String Pool 영역에 생성
        // new를 사용해서 생성하면 일반 heap 영역에 생성
        // String은 immutable 특성
        String test = "홍길동";
        String obj = new String("홍길동");
        System.out.println(name == test);     // true
        System.out.println(name == obj);      // false

        System.out.println(test.equals(obj)); // true
    }
}
```

### ArrayList

- Array와 유사
- 크기가 유동적
- 다른 데이터 타입 저장 가능 but 일반적으로 generic 사용해서 데이터 타입 통일
- Instance만 저장 가능 = Reference Data Type만 저장 가능

```java
package com.lecture.classes;

import java.util.*;

public class ArrayListTest {
    public static void main(String[] args) {
        // 배열
        String[] stringArray = new String[5];

        // ArrayList
        List<Object> list = new ArrayList<>();

        // 객체이기 때문에 당연히 method를 통해서 list 제어
        list.add("홍길동");
        list.add("안녕안녕!");

        // 원래는 primitive class 저장 불가능
        // but, JAVA는 wrapper class 제공
        // -> auto boxing
        list.add(100); // = list.add(new Integer(100));
        list.add(true);

        for (Object obj : list) {
            System.out.println(obj);
        }
    }
}

```

### HashMap

- 집합형 자료구조
- key, value의 쌍으로 저장
- key, value 둘 다 객체만 사용 가능
- 순서 개념 존재 하지 않음. but, 최근에는 효율성을 위해 존재

```java
package com.lecture.classes;

import java.util.*;

public class HashMapTest {
    public static void main(String[] args) {
        Map<Integer, String> map = new HashMap<>();
        map.put(1, "홍길동");
        map.put(2, "신사임당");

        System.out.println(map.get(1));
        System.out.println(map.get(2));
        System.out.println(map.get(3));
    }
}

```

### HashSet

- 중복제거

```java
package com.lecture.classes;

import java.util.*;

public class HashSetTest {
    public static void main(String[] args) {
        Set<String> set = new HashSet<>();

        set.add("홍길동");
        set.add("신사임당");
        set.add("강감찬");
        set.add("홍길동"); // 추가되지 않음

            System.out.println(iter.next());
        }
    }
}

```

### Exception

- 특정 상황이 발생하면 이 class의 Instace를 JVM이 생성
- 프로그램이 비정상 종료가 되는 걸 방지하기 위해 Exception Handling 필요

⇒ try - catch 구문

```java
package com.lecture.classes;

public class ExceptionTest {
    public static void main(String[] args) {
        System.out.println("Exception 발생");

        Object obj = null;
        try {
            // Exception 발생
            // 상황에 맞는 Exception을 JVM이 생성
            // 이 생성된 객체를 처리하지 않으면 프로그램 비정상 종료
            int result = 10 / 0;
            System.out.println(obj.toString());
        } catch (ArithmeticException e) {
            System.out.println("수학연산 오류");
        } catch (NullPointerException e) {
            System.out.println("null 포인터 오류");
        } catch (Exception e) {
            // 예외상황을 처리할 수 있는 처리 코드가 나옴
            System.out.println(e);
        } finally {
            System.out.println("무조건 실행");
        }
        System.out.println("프로그램 종료");
    }
}

```
