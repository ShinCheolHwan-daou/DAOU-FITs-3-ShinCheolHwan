## 객체 지향

### 상속과 관련된 constructor의 특징

- constructor는 상속되지 않는다.
- constructor가 호출될 때 자동적으로 상위 constructor 호출된다.

### method overriding

- Override annotation 사용한다.
- access modifier는 부모의 것과 같거나 더 넓어야 한다.
- field의 경우, overriding 되지 않고 shadow

```java
@Override
public void sleep() {
    super.sleep();
}
```

- 동적 바인딩 (field는 해당 되지 않는다)

### Is-A relationship

- sub class is a super class!
- 역은 성립하지 않는다.
- 다형성

```java
Student s = new Student();
Person p = new Student();
```

### this, super, this(), super()

```java
package inheritance;

public class Test extends SuperClass {
    int c = staticCall("6");
    static int d = staticCall("7");

    public Test() {
        // super -> field 생성 -> 초기화
        super(100);
        staticCall("8");
        super.myFunc();
    }

    @Override
    public void myFunc() {
        System.out.println("9");
    }

    public static void main(String[] args) {
        System.out.println("10");
        SuperClass sc = new Test();
        sc.myFunc();
    }
}

class SuperClass {
    static int staticCall(String msg) {
        System.out.println(msg);
        return 0;
    }

    int a = staticCall("1");
    static int b = staticCall("2");

    public SuperClass() {
        staticCall("3");
    }

    public SuperClass(int i) {
        // this()와 super()는 공존 불가능
        this();
        staticCall("4");
    }

    public void myFunc() {
        System.out.println("5");
    }
}
```

### final

- class : 상속 불가능
- method : override 불가능
- field : field 변경 불가능

### abstract class

- abstract class의 특징 : abstract class는 instance를 생성할 수 없다
- abstract class를 상속 받은 하위 class에서 abstract method를 overriding 한 후 instance 생성

### polymorphism & dynamic binding

- 다형성은 부모의 객체 타입으로 다양한 형태의 자식 객체를 생성,사용할 수 있는 것을 의미.

### Interface

- method는 무조건 public abstract



## 주요 class

### Object class

모든 class의 최상위 class

- 주요 methods
    1. equals()
    
    ```java
    public class MyObjectClass {
    
        String name;
    
        public static void main(String[] args) {
            MyObjectClass a = new MyObjectClass();
            MyObjectClass b = new MyObjectClass();
            a.name = "홍길동";
            b.name = "홍길동";
    
            System.out.println(a == b);
            System.out.println(a.equals(b));
        }
    
        @Override
        public boolean equals(Object obj) {
            MyObjectClass t = (MyObjectClass) obj;
            return t.name == this.name;
        }
    }
    ```
    
    1. toString()
    
    ```java
    @Override
    public String toString() {
        return String.format("%-7s", this.getName()) + " "
                + String.format("%-7s", this.getPrice()) + " "
                + this.getDescription();
    }
    ```
