## JDBC 기본 문법

### JDBC 개요

- Java Database Connectivity
- Java를 이용하여 Database에 있는 값을 활용하기 위한 API
- JDBC Driver : Java 응용 프로그램이 데이터베이스와 상호 작용할 수 있도록 하는 소프트웨어 구성 요소 (class & interface)

### JDBC 사용

1. (JDBC) Driver Loading   
    - 프로그램에서 딱 1번만 수행
2. Database 연결   
    - 만약 연결이 성공하면 연결 성공의 증표로 객체가 생성
    - 객체의 class는 java.sql.Connection   연결을 하려면 3가지 정보 필요
        - JDBC URL(어떤 데이터베이스에 접속하는지에 대한 정보) - thin 방식, oci 방식
        - ID
        - PW
3. SQL 작성   
    1. 일반 Statement     
        - 단순 / 기능상으로 부족
    2. PreparedStatement     
        - 코드 작성하기 편리
        - 효율 좋음
        - SQL Injection 방지
    3. CallableStatement 
        - tored Procedure을 호출 하기 위해 사용
4. Query 실행
    - `executeUpdate()`
        - SQL 구문이 INSERT, UPDATE, DELETE 계열일 때 사용
    - `executeQuery()`
        - SQL 구문이 SELECT 계열일 때 사용
5. 결과 처리
    - executeUpdate()
        
        ⇒ return 값은 SQL에 의해 영향을 받은 행의 수 (int)
        
    - executeQuery()
        
        ⇒ return 값은 `ResultSet`
        
6. 리소스 해제
    1. Connection
    2. PreparedStatement
    3. ResultSet
    
    ⇒ 사용된 자원을 해제
    

```java
package first;

// 책 제목에 대한 키워드를 입력받아서
// 책 제목에 해당 키워드를 포함하고 있는 책을 검색한 다음
// 해당 책에 대한 책 제목, 저자, 가격 정보를 출력하세요!

import java.util.*;
import java.sql.*;

public class SecondConnect {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("검색어를 입력해주세요.");
        String keyword = sc.nextLine();

        try {
            // 1. JDBC Driver Loading
            Class.forName("oracle.jdbc.driver.OracleDriver");

            // 2. Database 연결
            String JDBC_URL = "jdbc:oracle:thin:@localhost:1521:xe";
            String id = "C##JAVA_DEV";
            String pw = "1234";
            Connection con = DriverManager.getConnection(JDBC_URL, id, pw);

            // 3. SQL 작성
            String sql = "SELECT BTITLE, BAUTHOR, BPRICE FROM BOOK WHERE BTITLE LIKE ?";

            // 4. 쿼리 실행
            PreparedStatement pstmt = con.prepareStatement(sql);
            pstmt.setString(1, "%" + keyword + "%");
            ResultSet rs = pstmt.executeQuery();

            // 5. 결과 처리
            while (rs.next()) {
                System.out.printf("%s %s %s\n",
                        rs.getString("BTITLE"),
                        rs.getString("BAUTHOR"),
                        rs.getString("BPRICE")
                );
            }

            // 6. 리소스 해제
            rs.close();
            pstmt.close();
            con.close();

        } catch (Exception e) {
            System.out.println(e.getMessage());
        }
    }
}

```

### Transaction

작업의 최소 단위

- ACID
    - Atomicity (원자성) : All or Nothing
    - Consistency (일치성) : 제약 조건을 만족
    - Isolation (독립성) : Transaction 중간에 다른 Transaction 접근 불가능
    - Durability (영속성) : 종료된 Transaction은 영구히 저장

```java
con.setAutoCommit(false);
con.rollback();
con.commit();
```
