## Servlet Introduction
Web application에 대한 이론과 WebServer와 WAS를 포함하는 Apache Tomcat을 설치하고 WAS를 구성하게 할 수 있는 Servlet의 설정과 개념에 대해 배웠습니다.

### Server

```java
package org.example.helloservletproject;

import jakarta.servlet.ServletConfig;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

import java.io.IOException;
import java.io.PrintWriter;

@WebServlet("/my-servlet")
public class MyHello extends HttpServlet {

    public MyHello() {
    }

    // 기본적으로 overriding 해야되는 method
    // 1. init : class 초기화 함수
    @Override
    public void init(ServletConfig config) throws ServletException {
        System.out.println("MyHello init 호출");
        super.init(config);
    }

    // 2. service : 요청이 들어올 시 thread에서 실행
    //              client 요청이 Get 방식 : doGet 호출
    //              client 요청이 Post 방식 : doPost 호출
    //              일반적으로 override 하지 않음
    @Override
    protected void service(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        super.service(req, resp);
        System.out.println("MyHello service 호출");
    }

    // 3. doGet
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        System.out.println("MyHello doGet 호출");

        // 1. 클라이언트에게 연결된 데이터 통로 뚫기 (stream)
        PrintWriter out = resp.getWriter();

        // 2.
        out.println("<html><head></head><body>");
        out.println("<h1>Hello World</h1>");
        out.println("</body></html>");
        out.close();
    }

    // 3. doPost
    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        System.out.println("MyHello doPost 호출");
    }
}

```

### Client

1. protocol ⇒ **GET**
2. 서버의 ip ⇒ **localhost**
3. 서버의 포트번호 ⇒ **8080**
4. 프로젝트의 context ⇒ **HelloServletProject_war_exploded**
5. 해당 프로젝트의 Servlet에 대한 url mapping ⇒ **/my-servlet**
